### 4. Problema pedagògic: per a un principiant, els passos amb blanques són salts grans

Un alumne *segur* passa el 100 % a totes les caselles. Un alumne *normal* a velocitat lenta passa com a mínim el 69 % a tots els passos (L11 pas 5 i L28 pas 5), per sobre del 60 % que es demana. Els salts són del principiant (`alumne.txt`):

| D'un pas al següent | Principiant, lent | Normal, lent |
|---|---|---|
| L09 pas 5 → L10 pas 3 (primeres blanques) | 98 % → **39 %** | 100 % → 77 % |
| L11 pas 4 → pas 5 (quatre blanques) | 84 % → **30 %** | 94 % → 69 % |
| L15 pas 13 → pas 14 (primera meitat) → pas 16 (sencera) | 79 % → 25 % → **7 %** | 93 % → 90 % → 90 % |
| L24 pas 4 → pas 6 (dues vegades, a 76) | 48 % → **22 %** | 86 % → 83 % |
| L28 pas 3 → pas 5 | 64 % → **30 %** | 88 % → 69 % |

- **Causa:** en un ritme de 8 notes o menys no es perdona cap error (`Rhythm.swift`, línia 196: `errors <= notes.count / 8`), i una blanca escurçada ja és un error. El model de principiant escurça el 30 % de les notes llargues.
- **El salt de la L10 pas 3 no el vaig dir a la segona revisió:** és el primer contacte amb les blanques, i el principiant baixa del 98 % al 39 %.
- **Arranjament** (cap s'ha fet des de la segona revisió):
  - L10: abans del pas 3, un pas amb una sola blanca (`[long(C, 2)] + tones([C, C])`).
  - L11: abans del pas 5, un pas amb dues blanques i dues negres (`[long(C, 2)] + tones([E, E]) + [long(C, 2)]`).
  - L15: abans de cada meitat, dos trossos seguits (A+B, C+D).
  - El missatge de la blanca ja surt bé: no cal tocar el jutge per això.
